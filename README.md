# Binary

A command line util for getting the value of decimal numbers, hexadecimal numbers, characters and strings

## Installation

### From Source

For compiling from the source, you first need to have git, gcc and make installed, then, clone the repository and run make, you should get a compiled file named 'binary'

## Usage

You may add the file somewhere like /bin and run as such:

```console
binary <value> ...
```
